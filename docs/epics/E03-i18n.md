# E03 · Internationalization (EN / LT)

**Goal:** The whole UI is available in English and Lithuanian, with locale-aware dates, numbers and plurals.
**Milestone:** M1 · Walking skeleton
**Depends on:** E01

---

### E03-T01 · next-intl setup & locale routing — `M`
Integrate `next-intl` with `[locale]` segment (`/en/...`, `/lt/...`), middleware combined with Clerk middleware, default locale `lt`, detection from `Accept-Language` on first visit, message files `messages/en.json` and `messages/lt.json` organized by feature namespace.

**Acceptance criteria**
- [ ] Visiting `/` redirects to the detected or saved locale
- [ ] Server and client components can translate
- [ ] `<html lang>` matches the active locale

**Depends on:** E01-T01

### E03-T02 · Language switcher & persistence — `S`
Switcher in the avatar menu (and on the public landing page). Saved choice stored in a cookie and, once logged in, in `profiles.locale`.

**Acceptance criteria**
- [ ] Switching keeps the user on the same page
- [ ] Logged-in users get their saved locale on any device

**Depends on:** E03-T01, E04-T04

### E03-T03 · Formatting helpers — `S`
Helpers for dates (relative and absolute), numbers (kg with locale decimals), and plurals. Lithuanian plural rules (one / few / many / other) covered by ICU messages.

**Acceptance criteria**
- [ ] "1 serija / 2 serijos / 10 serijų" render correctly
- [ ] Dates shown in user's timezone and locale format
- [ ] Unit tests for both locales

**Depends on:** E03-T01

### E03-T04 · Missing-key check in CI — `S`
Script that fails CI when keys exist in one locale but not the other, or when a used key is missing.

**Acceptance criteria**
- [ ] CI fails on a mismatch with a clear message listing keys

**Depends on:** E03-T01, E01-T05

### E03-T05 · Translated catalog content — `S`
Seeded tags carry `label_en` / `label_lt`; seeded exercises and machines get LT names (user-created content stays as typed). Translation of tag labels shown according to active locale.

**Acceptance criteria**
- [ ] Tag chips display the label for the active locale
- [ ] Exercise search matches both EN and LT names for seeded exercises

**Depends on:** E06-T01

> Note: content translation for seeded exercises requires an `exercise_translations` table or `name_lt` column — decide in E06-T01 (see [open-questions.md](../open-questions.md)).
